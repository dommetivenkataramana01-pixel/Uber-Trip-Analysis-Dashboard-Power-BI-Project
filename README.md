# Uber-Trip-Analysis-Dashboard-Power-BI-Project
🚖 **Uber Trip Analysis Dashboard | Power BI Project**

I'm excited to share my Uber Trip Analysis Dashboard, a data analytics project I developed using **Microsoft Power BI**! 📊

The goal of this project was to analyze Uber trip data and transform it into meaningful insights through interactive visualizations.

🔍 **Key Highlights:**

📌 **Overview Analysis**
• Total Bookings and Total Booking Value  
• Average Booking Amount and Trip Distance  
• Average Trip Time  
• Booking trends by payment type and trip type  
• Vehicle type and location analysis  

⏰ **Time Analysis**
• Booking trends by pickup time  
• Day-wise booking patterns  
• Hour-and-day analysis using a heatmap  
• Peak and off-peak booking patterns  

🛠️ **Tools & Concepts Used:**
🔹 Microsoft Power BI  
🔹 DAX Measures  
🔹 Interactive Slicers and Filters  
🔹 Data Visualization  
🔹 KPI Analysis  
🔹 Dashboard Design  

💡 **Key Learning:**

This project helped me improve my understanding of Power BI, data visualization, business requirements, and how to present data in a way that supports data-driven decision-making.
